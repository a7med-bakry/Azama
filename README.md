# عظمة — Clip Agency Manager

نسخة V1 من تطبيق إدارة وكالة صفحات الكليبرز.

## المميزات
- إدارة حسابات Whop و Content Rewards.
- Email / Username / أرباح الشهر.
- إدارة قنوات YouTube لكل حساب.
- إدارة فيديوهات كل قناة.
- حالة الفيديو: مقبول / مرفوض.
- الربح وموعد تسليم الربح.
- اختيار التاريخ والساعة من `datetime-local`.
- حفظ محلي Offline باستخدام LocalStorage.
- إعادة تصفير أرباح الحسابات تلقائياً عند بداية شهر جديد.
- متوافق مع GitHub Pages بدون Backend.

## التشغيل على GitHub
1. أنشئ Repository جديد.
2. ارفع `index.html` و `styles.css` و `app.js`.
3. من Settings → Pages اختر Deploy from branch.
4. اختر Branch: `main` و Folder: `/ (root)`.
5. افتح الرابط الذي يعطيه GitHub Pages.

> البيانات في هذه النسخة محفوظة على الجهاز/المتصفح فقط. حذف بيانات المتصفح قد يحذفها.
